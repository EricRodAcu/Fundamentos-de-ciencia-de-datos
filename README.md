## 🚀 Empieza aquí

Si es tu primera vez en mi perfil, estos dos proyectos resumen bien lo que hago — el punto de
encuentro entre geoestadística clásica y machine learning:

| Proyecto | En simple, ¿qué hace? |
|---|---|
| **[Estimación de recursos con incertidumbre geológica](https://github.com/EricRodAcu/Fundamentos-de-ciencia-de-datos/blob/main/estimacion_recursos_python_v2.ipynb)** | Predice qué tipo de roca y qué ley de mineral hay en zonas de una mina que no se han perforado todavía, y calcula cuánto valen esos recursos en distintos escenarios — usando Machine Learning en vez del método clásico de simulación geoestadística. |
| **[Optimización de modelos predictivos](https://github.com/EricRodAcu/Fundamentos-de-ciencia-de-datos/blob/main/optimizacion_modelos_predictivos.ipynb)** | Construye y ajusta modelos de Machine Learning (Random Forest) de forma responsable — sin fugas de datos y con validación honesta — el mismo enfoque que se puede aplicar para estimar ley de mineral o tonelaje a partir de datos de sondaje. |
